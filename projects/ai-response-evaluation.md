Project 2: AI Response Evaluation

Project Overview

Project type: Practice evaluation project
Task: Evaluate AI-generated responses against a user's request
Objective: Assess instruction following, factual accuracy, relevance, clarity, and completeness.

All examples below are original practice scenarios created for this portfolio.

Evaluation Criteria

- Instruction following: Did the response follow the user's instructions?
- Accuracy: Is the information factually correct?
- Relevance: Does it answer the question asked?
- Clarity: Is it easy to understand?
- Completeness: Does it address the important parts of the request?

Ratings use a three-point scale:

- 3 — Good: Meets the criterion.
- 2 — Needs improvement: Partially meets the criterion.
- 1 — Poor: Does not adequately meet the criterion.

Evaluation Examples

Example 1: Simple factual question

User prompt: What is the capital of Nigeria?

AI response: Lagos is the capital of Nigeria.

Evaluation:

- Instruction following: 3
- Accuracy: 1
- Relevance: 3
- Clarity: 3
- Completeness: 1

Overall judgment: Poor

Reasoning: The response is clear and relevant but factually incorrect. Abuja is the capital of Nigeria. This illustrates why factual accuracy must be checked independently of writing quality.

Example 2: A request for three items

User prompt: Name three fruits.

AI response: Mango, orange, and banana.

Evaluation:

- Instruction following: 3
- Accuracy: 3
- Relevance: 3
- Clarity: 3
- Completeness: 3

Overall judgment: Good

Reasoning: The response gives exactly three recognizable fruits and directly satisfies the request.

Example 3: An incomplete answer

User prompt: Give me two benefits of regular exercise and explain each briefly.

AI response: Regular exercise improves heart health and can improve mood.

Evaluation:

- Instruction following: 2
- Accuracy: 3
- Relevance: 3
- Clarity: 3
- Completeness: 2

Overall judgment: Needs improvement

Reasoning: The response identifies two valid benefits, but it does not explain either one. It answers part of the request but misses an explicit instruction.

Quality Assurance Checklist

Before submitting an evaluation:

1. Read the entire user prompt.
2. Identify every explicit instruction.
3. Check factual claims rather than relying on confident wording.
4. Apply the same rating scale consistently.
5. Support judgments with specific evidence from the response.
6. Avoid treating a fluent response as automatically correct.

Key Learning

A high-quality AI response must do more than sound convincing. It should be accurate, relevant, clear, complete, and aligned with the user's instructions.

Project Status

Completed as a self-directed practice exercise. The examples are not paid client work or an assessment conducted for an AI company.
